## AkkoCloud是何方神圣

AkkoCloud这家商家2019年开的张，算是个国人办的云服务品牌，二次元气质拉满那种。最早它家主要做国内独立服务器，后来慢慢把业务铺到了海外，现在美国圣何塞、德国法兰克福、英国伦敦都有机房，听说香港那边也有独立服务器。

它家主打的一个卖点就是CN2 GIA线路。这玩意儿简单说就是中国电信的高端精品线路，延迟低、稳定性好，尤其适合国内用户访问海外服务器。AkkoCloud的海外VPS清一色KVM架构，三网回程都强制走CN2 GIA，电信和联通去程也走GIA，移动去程则是直连。这套组合拳打下来，国内访问速度确实能打。

付款方式目前只支持支付宝，界面是全中文的，对国人用户来说上手没什么门槛。说实话这点既是优势也是限制——方便是真方便，但你要是想用PayPal或者信用卡可能就得绕道了。

AkkoCloud的海外VPS现在主要三个机房可选，每个机房的定位和线路细节略有不同。
